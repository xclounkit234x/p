Compressed bookmarklet

Generated from gun.js, minified in-browser and fully inlined. Once copied, it does not require a CDN.

Install

  1. Create a browser bookmark called Element Sniper 2.5.
  2. Generate and copy the compressed bookmarklet.
  3. Paste it into the bookmark URL field.
  4. Activate it on any page.

Open Shadow DOM and same-origin iframe inspection are best-effort. Cross-origin frames and closed Shadow Roots are browser-isolated. The tool hides elements; it does not send network requests or modify page content beyond the selected element's visibility.
