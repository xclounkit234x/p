ELEMENT
SNIPER.

A tiny arcade-style element picker. Aim, lock, fire, clear page elements, and undo your shots. Runs locally in the current tab after activation.

Bookmarklet source is built from gun.js on this page.

Install the bookmarklet

  1. Create a browser bookmark.
  2. Name it Element Sniper 2.1.
  3. Paste the copied JavaScript into the bookmark URL field.
  4. Open any page and activate the bookmark.

Detection uses composed event paths, elementFromPoint, open Shadow DOM hit-testing, and text-node normalization. Cross-origin iframe contents and closed Shadow DOM are browser-isolated and cannot be inspected by a parent-page bookmarklet.
